## Chapter-1: Introduction
- Install GCC on your OS. I'm using WSL2 on Windows, but it's better to run Linux Natively for it.
- Try out any of the Files from the Repo as a test file. If possible, build a makefile in your setup, in order to automate most of the commands.
- Use '-Wall -Wextra -pedantic -std=c23' flags to run it. If you get a warning, fix it instead of letting it slip.
