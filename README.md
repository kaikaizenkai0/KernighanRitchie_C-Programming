# Notes on _The C Programming Language_ (K&R)

Personal notes and key takeaways from reading **"The C Programming Language"** by Brian W. Kernighan and Dennis M. Ritchie — the definitive guide to C by the language's creators.

---

## About This Repo

This repository contains code examples as I work through K&R's _The C Programming Language_ (2nd Edition, ANSI C). It's meant to serve as both a personal study aid and a resource for anyone else working through the book.

---


## How It's Organized
- Each Chapter gets it's own folder. The code is arranged according to the subtopics in Chronological order.
- Most of it is just the code example, with just the core concept in the comments. THIS IS NOT A REPLACEMENT OF THE BOOK, JUST A SUPPLEMENTARY GUIDE.
## Who Is This For?

- Self-learners working through K&R independently
- Students who want a supplementary reference
- Experienced programmers brushing up on C fundamentals
- Anyone curious about the book that helped shape modern systems programming

---

## About the Book

> _"The C Programming Language"_ by Brian W. Kernighan and Dennis M. Ritchie remains one of the most influential programming books ever written. First published in 1978, it introduced millions of programmers to C and laid the foundation for countless languages that followed.
